# HR-Analytics-Dashboard-PowerBI

## Overview
A comprehensive HR Analytics Dashboard built in Power BI to provide actionable workforce insights. The dashboard analyzes employee  active workforce distribution, age demographics, department-wise attrition, and job satisfaction ratings through interactive visualizations, KPI cards, DAX calculations, and dynamic filtering capabilities.

## Key Metrics

- Attrition Count

- Average Age

- Department-wise Attrition Analysis
- Education Field-wise Attrition
- Age Group Analysis
- Job Satisfaction Ratings
